# AI 面试陪练（ai-mock-interview）

> 输入公司、岗位和 JD，AI 联网搜索面经并出题，模拟 AI 视频面试的限时作答与追问，逐题评分并给出改进建议。

🚀 **在线使用**：[isabellae1.github.io/ai-mock-interview](https://isabellae1.github.io/ai-mock-interview/)（v0.1，开发中）

## 使用方法

1. 准备一个模型 API Key。推荐 [阿里云百炼](https://bailian.console.aliyun.com/)（通义千问），它支持联网搜索面经；也支持 Kimi 和 DeepSeek（不联网，只根据 JD 出题）
2. 打开网页，在「设置」里填入 API Key
3. 填写公司、岗位和 JD（可选：简历），点「搜索并生成题目」
4. 确认题目后开始模拟：15 秒准备 → 限时作答（可语音或打字）→ AI 追问 → 评分
5. 一轮结束后查看总结，导出为 Markdown 复盘

建议使用 Chrome 或 Safari 的最新版本。

### 关于费用（通义千问）

- 阿里云百炼的账号需要**完成实名认证**，才能使用模型和领取新用户免费额度
- 免费额度按模型发放，请在百炼控制台「免费额度」页面确认所用模型（默认 `qwen3.7-plus`）有额度；模型名称可在「设置」中修改
- **联网搜索按次单独计费，不在免费额度内**。账户余额为 0 时使用联网搜索会导致欠费（报错 `Arrearage`），所有调用都会被暂停。可以先充值少量余额，或在「设置」中关闭联网搜索
- 建议在免费额度页面为所用模型打开「用完即停」，避免意外扣费

## 为什么做这个

越来越多公司的校招第一轮是 AI 视频面试：每题 15 秒准备、限时作答，AI 根据你的回答追问，再按逻辑结构和关键词打分。准备时最大的问题是：面经零散、写出来的答案和说出来的效果差很多、没有人追问和反馈。

这个工具想解决的就是这三件事。

## 计划功能

- 🔍 **针对性出题**：根据公司、岗位、JD 和简历，联网搜索公开面经和公司信息后出题；每道题标注来源（面经 / JD 推测 / 简历），不把推测的题冒充成真实面经
- 🔊 **语音提问**：面试官用语音读出题目和追问，可以重听
- ⏱ **还原真实节奏**：15 秒准备 + 限时作答，时间到自动提交；可随时结束本轮查看总结
- 🎙 **口头作答**：支持语音转文字，也可以直接打字
- 📎 **上传简历**：支持 PDF / Word / TXT，在浏览器本地读取，自动隐藏手机号、邮箱、身份证号和出生日期
- 💬 **AI 追问**：根据你的回答追问 1–2 次
- 📊 **逐题反馈**：结论先行、结构清晰、具体数据、岗位关键词四个维度评分，并给出参考回答
- 🔒 **隐私**：没有服务器，API Key、简历和作答记录只保存在你自己的浏览器里
